# موجز الأحكام (MojazAhkam)

> Flutter mobile application providing simplified Shia Islamic rulings (الأحكام الشرعية) for everyday questions, with Arabic-first design and full offline support.

## ✨ Features

- 📚 **Curated database** of Shia Islamic rulings, organized by topic and category
- 🔍 **Fast Arabic full-text search** across thousands of entries
- 🌙 **Dark mode** with Arabic-optimized typography (Tajawal, Cairo)
- 📱 **Full RTL UI** designed for Arabic-speaking users
- 💾 **Offline-first** — all content available without internet connection
- 🔖 **Bookmarking and personal notes** for frequently referenced rulings
- 🎨 Smooth animations and modern Material Design 3 interface

## 📦 Getting Started

```bash
# Clone the repository
git clone https://github.com/alialrikabi313/MojazAhkam.git
cd MojazAhkam

# Install dependencies
flutter pub get

# Run on a connected device or emulator
flutter run
```

**Requirements:** Flutter SDK 3.x or later, Dart 3.x or later, Android Studio / Xcode for platform builds.
